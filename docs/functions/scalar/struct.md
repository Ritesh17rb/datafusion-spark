# Struct Functions (scalar functions)

Part of the [datafusion-spark function reference](../README.md).

- [struct](#struct)

## `struct`

Creates a non-NULL struct, retaining NULL fields. Unnamed expressions use one-based field names `col1`, `col2`, etc., rather than DataFusion's `c0`, `c1`, etc. The Spark SQL planner and Rust expression helper retain column and nested field names. The physical UDF and Rust helper accept zero arguments for an empty struct, but DataFusion's SQL parser currently rejects `struct()`. SQL calls mixing explicit aliases and unnamed arguments still receive DataFusion's generated names for unnamed fields, because those names are assigned before the Spark planner.

```sql
struct(expr, ...)
```

### Arguments

- **expr**: Zero or more expressions of any type.

### Example

```sql
> SELECT struct(1, 2, 3);
{col1: 1, col2: 2, col3: 3}
```
